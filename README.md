# Analysis and Design of Algorithms (ADA)

This repository contains my **Analysis and Design of Algorithms (ADA) Lab** programs, implementations, and problem-solving practice.

The main focus of this repository is understanding different algorithmic techniques, analyzing their **time and space complexity**, and implementing them using **C++**.

## 📚 Topics Covered

- Searching Algorithms
- Sorting Algorithms
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort
  - Cyclic Sort
- Divide and Conquer
- Recursion
- Greedy Algorithms
- Dynamic Programming
- Binary Search
- Two Pointer Techniques
- Array Problems
- LeetCode Problems based on algorithmic patterns
- Time and Space Complexity Analysis

 ## language used : c++

## ⏱️ Complexity Analysis

For each algorithm, I try to understand and analyze:

- **Time Complexity**
- **Space Complexity**
- **Auxiliary Space**
- **Best, Average, and Worst Case** where applicable
